GitHub Pages (무료 주소) 배포 방법

서버 비용 0원으로 `your-id.github.io` 형태의 나만의 굿즈 사이트를 만드실 수 있습니다!

  1. GitHub 회원가입 및 저장소(Repository) 생성:
    GitHub 로그인 후 New repository 생성 (예: seno-goods).
  2. index.html 파일 업로드 및 수정 방법:
    이 코드를 복사하여 index.html 이름으로 저장소에 업로드합니다.
    💡 깃허브 배포 후에도 언제든지 index.html을 편집(Edit)하여 로고, 텍스트, 굿즈 목록을 자유롭게 수정하실 수 있습니다.
  3. GitHub Pages 활성화:
    저장소 Settings → Pages → Branch를 main으로 지정 후 Save.
  4. 배포 완료!
    1~2분 뒤 https://your-id.github.io/seno-goods/ 주소로 접속 가능합니다.
💡 굿즈 데이터 수정 방법: 코드 내부의 SAMPLE_GOODS 배열 항목의 제목, 이미지URL, 가격, 연도 등을 수정하여 저장(Commit)하면 즉시 사이트에 반영됩니다!
